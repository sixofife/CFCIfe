## 👨🏾‍💻 About Me

I'm a **Cloud/DevOps engineer and backend developer** with a background in technical support for cloud platforms, particularly Microsoft Azure.

My work and learning have gradually moved from troubleshooting individual cloud workloads toward **infrastructure, automation, Kubernetes, CI/CD, and platform engineering**.

I've worked with production cloud environments while supporting customers using services such as **Azure App Service, Azure Functions, and Azure DevOps**, and I've built automation around cloud deployments using **PowerShell, ARM/Bicep, and Azure tooling**.

More recently, I've been focusing heavily on **Kubernetes, Terraform, Google Cloud Platform, AWS, CI/CD, observability, and infrastructure automation**, while continuing to build backend applications and APIs.

### 🔭 What I'm currently focused on

- ☁️ Cloud infrastructure and platform engineering
- ☸️ Kubernetes and managed Kubernetes platforms such as GKE and EKS
- 🏗️ Infrastructure as Code with Terraform
- 🚀 CI/CD and deployment automation
- 🔐 Cloud security, secrets management and identity
- 📊 Observability, troubleshooting and incident investigation
- 🐳 Docker and containerized workloads
- ⚙️ Backend development with Node.js / NestJS
- 🗄️ Databases and API development
- 🧪 Building projects to turn theory into practical experience
